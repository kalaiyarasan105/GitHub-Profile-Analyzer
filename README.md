# GitHub Profile Analyzer

A modern web application to analyze GitHub profiles and generate detailed PDF reports.

## Features

- 🔍 Search any GitHub username
- 📊 View comprehensive statistics dashboard
- 📈 Interactive charts for language usage and repository stats
- 📄 Download professional PDF reports
- 🎨 Modern glassmorphism UI design
- 📱 Fully responsive design

## Technologies Used

- HTML5
- CSS3 (Glassmorphism effects)
- JavaScript (ES6+)
- Chart.js for data visualization
- html2pdf.js for PDF generation
- GitHub REST API
